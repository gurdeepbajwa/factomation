Why it's like this

Why invoices lock at 23:00

The old bank export ran at 23:30 and read the invoices table directly. Locking at 23:00 kept totals still while it ran. The export moved to the API in 2023, so the lock may no longer be needed.

From: engineer, session 4 · git blame on month_end.php

Two admins

The new admin was built beside the old one to avoid a big-bang switch. Finance still uses the old one for credit notes.

From: engineer, session 2
